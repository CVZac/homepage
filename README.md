# CV-Etron 官网

> 以人为核，智能环绕。People at the core. Intelligence in orbit.

单页官网，中英双语，目标是让客户一眼看清 **业务范围** 和 **具体费用**。

整个网站只有一个文件 `index.html`（样式和脚本都写在里面），双击就能在浏览器打开，也可以直接上传到任何静态托管服务。

## 页面结构

| # | 版块 | 锚点 | 内容 |
|---|------|------|------|
| — | 首屏 | `#home` | 品牌标语、一句话介绍、核心数据 |
| 01 | 业务范围 | `#services` | 三项服务：包含 / 不包含 / 周期 / 需客户准备的内容 |
| 02 | 价格方案 | `#pricing` | 三项服务的套餐价格、企业定制（邮件咨询）、按需加价、付款与保障 |
| 03 | 费用计算器 | `#calculator` | 勾选服务实时算出首年费用，一键发邮件获取正式报价 |
| 04 | 合作流程 | `#process` | 6 个步骤，每步的用时和需要客户配合的事项 |
| 05 | 客户案例 | `#cases` | 案例 + 客户评价（目前是占位内容） |
| 06 | 关于我们 | `#about` | 品牌故事与价值观 |
| 07 | 常见问题 | `#faq` | 以费用相关问题为主 |
| 08 | 联系我们 | `#contact` | 邮箱 + 留言表单（打开邮件应用发送，不需要后端） |

## 修改价格

打开 `index.html`，搜索 `价格配置`，所有价格都集中在 `PRICING` 对象里：

```js
const PRICING = {
  deploy:   { starter: 19800, pro: 59800, flagship: 128000 },   // 部署：一次性 / 项目
  support:  { basic: 2980, allday: 6980, premium: 12800 },      // 售后：每月
  advisory: { single: 3800, quarterly: 36000, annual: 128000 }, // 顾问：每次 / 每季度 / 每年
  addons:   { integration: 8000, kb: 3000, onsite: 3000, training: 4000, visit: 1500 },
  rushRate: 0.20,                 // 加急：部署费 +20%
  annualRate: 0.85,               // 售后年付：85 折
  bundle: { 2: 0.95, 3: 0.90 },   // 组合优惠：2 项 95 折，3 项 9 折
};
```

改完后，价格卡片、业务范围里的起价和计算器会自动同步。

还有几处是写死在文字里的数字，调价时也要一起改（搜索对应文字即可）：

- HTML 里带 `data-price` 的标签内的默认数字（页面加载后会被自动覆盖，但搜索引擎看到的是这些默认值）
- 年度顾问卡片上的「比按季度购买省 ¥16,000」
- 「按需加价」表格中的「部署费 +20%」「硬件价 × 5%」
- 客户案例里的「首年约 ¥X 万」

## 上线前需要替换的占位内容

- [ ] 「关于我们」中关于 Etron 名字含义的品牌故事，请确认是否符合公司实际

- [ ] 页脚 ICP 备案号（服务器在中国大陆时必须添加，搜索 `ICP`）

## 部署

任意静态托管都可以，例如：

- **GitHub Pages**：仓库 Settings → Pages → 选择分支，根目录即可
- **国内服务器 / 对象存储**（阿里云 OSS、腾讯云 COS 等）：上传 `index.html`；国内访问需要完成 ICP 备案

## 技术说明

- 双语：语言切换会被记住（浏览器本地存储）；也可以用 `?lang=en` 或 `?lang=zh` 直接打开指定语言。默认按访客的浏览器语言选择。
- 字体：英文使用 Inter / Inter Tight，从 Google Fonts 异步加载；国内访问不到时会自动回退到系统字体（苹方、微软雅黑等），不会卡住页面。
- 无障碍：支持键盘操作和读屏软件；开启「减少动态效果」的访客不会看到动画。
