# CV-Etron 云想亿创 官网

> 以人为核，智能环绕。People at the core. Intelligence in orbit.
>
> 云想亿创：点子在云上，亿万人一起创造。

单页官网，中英双语，目标是让客户一眼看清 **业务范围** 和 **具体费用**。

整个网站只有一个文件 `index.html`（样式和脚本都写在里面），双击就能在浏览器打开，也可以直接上传到任何静态托管服务。

### 五条业务与价格的对应

前三条业务对应网站上明码标价的服务：企业级 AI 基础设施、普惠算力 → 部署与售后套餐；AI 商业验证 → 总裁 AI 顾问。早期融资对接按项目沟通（邮件咨询），赋能独立创业者引导预约免费沟通。业务卡片里的要点是根据业务描述整理的，可在 `index.html` 中搜索 `biz-1` 至 `biz-5` 修改。

## 修改价格

打开 `index.html`，搜索 `价格配置`，所有价格都集中在 `PRICING` 对象里：

```js
const PRICING = {
  deploy:   { starter: 19800, pro: 59800, flagship: 128000 },   // 部署：一次性 / 项目
  support:  { basic: 2980, allday: 6980, premium: 12800 },      // 售后：每月
  advisory: { single: 3800, quarterly: 36000, annual: 128000 }, // 顾问：每次 / 每季度 / 每年
  addons:   { integration: 8000, kb: 3000, onsite: 3000, training: 4000, visit: 1500 },
  rushRate: 0.20,                 // 加急：部署费 +20%
  annualRate: 0.85,               // 售后年付：85 折
  bundle: { 2: 0.95, 3: 0.90 },   // 组合优惠：2 项 95 折，3 项 9 折
};
```

改完后，价格卡片、业务范围里的起价和计算器会自动同步。

还有几处是写死在文字里的数字，调价时也要一起改（搜索对应文字即可）：

- HTML 里带 `data-price` 的标签内的默认数字（页面加载后会被自动覆盖，但搜索引擎看到的是这些默认值）
- 年度顾问卡片上的「比按季度购买省 ¥16,000」
- 「按需加价」表格中的「部署费 +20%」「硬件价 × 5%」

## 交付案例

案例区在首屏之后、占满整行：左侧是 6 个案例的列表（名称、一句话场景、参考首年费用），右侧是可直接操作的看板。案例由访客自己点选，不自动轮播；支持方向键切换。宽度不足 1100px 时，案例列表变为顶部横向滑动。

| 案例 | 看板内容 | 可以怎么操作 |
|---|---|---|
| 学生评估 | 综合评分与近 6 次走势、六维素质雷达、各科成绩区间、本周聚焦待办 | 悬停查看明细；勾选待办 |
| AI 考官 | 合格人数、平均站分、AI 一致性；6 个考站成绩分布；所选考站的可靠性 | 悬停查看考生分数；点击考站查看 κ、ICC、复核与改判 |
| 物业管理 | 收缴、响应、满意度、投诉；团队健康度与各项目对比；近 12 个月走势 | 悬停或方向键逐月查看；点击时间轴节点查看事件 |
| 健康管理 OS | 健康评分、心率、睡眠、运动；近 14 天睡眠；体检指标与参考范围；AI 健康建议 | 悬停查看每天睡眠和每项指标 |
| 日程管理 | 会议数、会议时长、专注时间；下周日历；时间分配；AI 排程建议 | 悬停查看日程；一键采纳 AI 建议，日历、指标和时间分配同步变化，可撤销 |
| 资产配置 OS | 总资产、收益、回撤、夏普比率；组合净值与基准；当前与目标配置；调仓建议 | 悬停或方向键逐月查看净值；悬停查看各类资产金额 |

- **修改数据**：在 `index.html` 的脚本里搜索 `EDU`、`EXAM`、`PROP`、`HEALTH`、`SCHED`、`ASSET`。所有统计（如平均睡眠、会议时长、收益与回撤、调仓金额）都由这些数据计算，彼此一致。
- **修改文字**：看板静态文字在 HTML 中（搜索 `scp-` 加案例名），图表里的文字在脚本的 `SCT`（前三个案例）和 `SCX`（后三个案例）中，中英各一份。
- **参考配置**：写在面板底部的 `data-preset` 和 `data-estimate` 上，两处保持一致。首年费用按 `PRICING` 自动计算，与计算器结果一致；左侧列表里的价格也会自动同步。
- **新增案例**：在左侧列表复制一个按钮（`sct-…`），在看板区复制一个面板（`scp-…`），改成新的 id，并让按钮的 `aria-controls` 指向新面板。
- **图表配色**：经过色盲安全校验。系列用蓝、青、橙（资产配置用前五个分类色），状态用绿、黄、红并配图标或形状，不只靠颜色。
- 所有机构、人物和数字都是演示样例，案例区标题和看板下方都注明了「界面为交付物示意，数据为演示样例」。

## 内容说明

- 网站上没有编造的客户案例、评价或业务数据。有了真实案例和客户授权的评价后，可以加在「为什么是我们」版块之后。
- 商务条款（付款节奏 50% / 40% / 10%、首次顾问会谈不满意全额退款、6% 增值税发票、各档售后响应时间）已确认。
- ICP 备案号（京ICP备2026070946号）在页脚，链接到工信部备案查询网站。

## 部署

任意静态托管都可以，例如：

- **GitHub Pages**：仓库 Settings → Pages → 选择分支，根目录即可
- **国内服务器 / 对象存储**（阿里云 OSS、腾讯云 COS 等）：上传 `index.html`，并绑定已备案的域名

## 视觉主题

- **配色**：曜石黑 `#07080A` 打底，云银白 `#EEF1F5` 作文字和主按钮，冰川蓝 `#A9BCFF` 只用于选中状态、勾选、强调字等少量点缀。色值都在 `index.html` 开头的 `:root` 里，改一处全站同步。
- **主按钮**：白底黑字（`--primary`）；企业定制等次要按钮为冰川蓝描边。
- **背景流动线条**：一块固定在内容下方的画布，画两束缓慢流动的细线丝带，滚动页面时流速会略微加快。正文区域的线条自动减弱，不影响阅读。约 30 帧/秒，切到其他标签页时暂停；开启「减少动态效果」的访客看到的是静止线条。调整亮度、数量、走向：搜索 `ribbons`。
- **图表配色**：看板图表仍使用经过色盲校验的蓝 / 青 / 橙与状态色，在新底色上重新校验通过。

## 技术说明

- 双语：语言切换会被记住（浏览器本地存储）；也可以用 `?lang=en` 或 `?lang=zh` 直接打开指定语言。默认按访客的浏览器语言选择。
- 字体：英文使用 Inter / Inter Tight，从 Google Fonts 异步加载；国内访问不到时会自动回退到系统字体（苹方、微软雅黑等），不会卡住页面。
- 无障碍：支持键盘操作和读屏软件；开启「减少动态效果」的访客不会看到动画。
